企業導入 AI Agent
的 任務地圖

9 種任務・1 套 8 步驟骨架・4 大類型
共通骨架｜為什麼每張卡都是 8 步
不管是剪影片、做簡報、跑報表還是查競品，Agent 的工作邏輯其實完全一樣—— 先理解、再決策、後產出、最後把關。換的只是工具與產出物，骨架不變。 這就是為什麼一套流程學會，可以套進公司裡的每一個部門。

PHASE 4
07 – 08

任務分類｜企業導入 AI 的三種主戰場
類型 A

內容生成型

風險：品質與合規用語
01剪影片素材解析 → 語音理解 → 剪輯決策 → QA 定稿 02行銷簡報需求定義 → 敘事架構 → 文案圖表 → 組裝覆核 03短影音腳本選題定位 → Hook 設計 → 分鏡字幕 → 合規檢查
類型 B

數據彙整型

風險：數字正確與行動落地
04財務月報表資料串接 → 清洗計算 → 差異分析 → 覆核簽名 05營運數據週報指標定義 → 週期比對 → 異常偵測 → 行動追蹤
類型 C

檢索稽核型

風險：來源真實性與判定越權
06競品分析範圍界定 → 廣度蒐集 → 來源驗證 → 人工判讀 07法規合規查核適用界定 → 條文取得 → 逐項比對 → 專業覆核 08品質 QA 稽核標準彙整 → 抽樣規劃 → 缺失分級 → 複核結案
類型 D

研發探索型

風險：最高，僅能輔助
09研究配方輔助法規框定 → 證據分級 → 風險預檢 → 專業定案
導入判斷｜Agent 該做到哪裡就停
任務類型Agent 負責人一定要接手的地方
內容生成型發想、草稿、套版、大量產出品牌調性、療效與廣告用語把關
數據彙整型取數、計算、比對、標記異常歸因判斷與對外數字的簽核
知識檢索型廣度蒐集、交叉比對、整理成表來源查證與結論可信度判讀
研發探索型文獻檢索、候選組合、風險提示最終配方決策、實驗與法規驗證
💡 一句話總結整個系列：Agent 越往下走越不能自己做決定。 內容型可以讓它端到端跑完，數據型要人做歸因，檢索型要人查來源，研發型只能當助手。 導入 AI 的成敗，不在於 Agent 能做多少，而在於你有沒有把「人該接手的那一步」設計進流程裡。
